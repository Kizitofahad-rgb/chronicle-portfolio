# Kizito Fahad — Chronicle

Animated personal portfolio for Kizito Fahad, built with React and Vite.

## Included

- Cinematic game-inspired portfolio interface
- Projects, achievements, and certificates
- Downloadable CCNA, OpenAI Academy, and Anthropic Claude 101 certificates
- Responsive navigation, soundtrack toggle, and contact links

## Run locally

Use pnpm from the repository root, then run the Chronicle portfolio workflow or the package dev script.
